# Cowork adapter

A Cowork plugin: three skills plus a small CLI that wraps the core scheduler. The plugin is assembled by `build.sh`, which copies `core/scheduler.js` and `packs/default/` into `plugin/vendor/` so the plugin never drifts from the repo, then zips the result to `dist/stretchbreak.plugin`.

```
adapters/cowork/
├── build.sh                 # vendor core + packs, validate, zip → dist/stretchbreak.plugin
├── plugin/
│   ├── .claude-plugin/plugin.json
│   ├── README.md            # what the user sees when installing
│   ├── scripts/sb.js        # CLI: pick | card | show | today | snooze | list | config
│   ├── skills/
│   │   ├── stretch-break/   # ambient: ask once per task, then show a card before long waits
│   │   ├── stretch/         # on demand, optional body area
│   │   └── stretch-settings/# plain-language preferences → config.json
│   └── vendor/              # generated by build.sh; not committed
└── dist/                    # generated; not committed
```

## Build

```
adapters/cowork/build.sh
```

Install the resulting `.plugin` file in Cowork.

## How the card is rendered

`sb.js show` prints one JSON line, a `---` separator, then a self-contained HTML fragment (cue, numbered steps, Feel and Avoid lines, countdown bar) styled with Cowork's CSS variables (light and dark). The skill hands that fragment to Cowork's inline widget renderer; if that tool is unavailable in a session it prints the same content as plain text. Rendering is done by the script rather than by the model so every card looks the same and the instructions are never paraphrased.

## Testing the CLI without Cowork

```
export STRETCHBREAK_HOME=/tmp/sbtest      # keep test state out of ~/.stretchbreak
node adapters/cowork/plugin/scripts/sb.js show --wait 60 --force
node adapters/cowork/plugin/scripts/sb.js config set posture seated
node adapters/cowork/plugin/scripts/sb.js list
```

Run `build.sh` first so `plugin/vendor/` exists.
